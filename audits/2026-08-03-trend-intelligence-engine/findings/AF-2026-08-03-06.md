## Severity
- [x] Minor
## Description
A terminal delivery failure fails the whole run (loud, non-silent — good) but there is
no dead-letter store to retry a single failed record independently.
## Evidence
- src/trendengine/pipeline.py terminal path; docs/error-handling.md "Not yet covered".
## Impact
Low: runs are idempotent and re-runnable, so a failed delivery is recovered by re-running.
A DLQ would avoid re-processing the whole batch.
## Root Cause
Scope choice: whole-run retry over per-record dead-lettering for a small batch.
## Recommendation
If batch sizes grow, add a small persisted DLQ (see the kit's database/schema.sql pattern).
