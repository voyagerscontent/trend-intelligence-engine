# Audit Finding — AF-2026-08-03-03
System: Trend Intelligence Engine | Related audit: 2026-08-03/scorecard.md
Domain: 2.10 Testing / 2.9 Reliability (live integration) | Reported by: Claude | Date opened: 2026-08-03
## Severity
- [x] Critical (for the "real trends from live APIs" scope; not for the sample/dry scope)
## Description
All source adapters (Ahrefs, GSC, Google Trends, social, news, brand-radar) currently
return SAMPLE signals; the live API calls are stubbed with `TODO(live)`. The deployed
system therefore produces sample-derived briefs, not real market trends.
## Evidence
- src/trendengine/sources/*.py — each has a `TODO(live)` and a `_sample()` fallback.
## Impact
Go-live in the sense of "acts on real market data" is not met until at least one source
is wired and tested against a real API. Safe for internal demonstration / pipeline
validation now.
## Root Cause
Intentional scaffold stage (documented as P1-1 in docs/requirements.md).
## Recommendation
Wire Ahrefs first against staging, add a rate-limit/timeout test (obs.request_with_retries
with injected sleep), record a dated staging run, then re-score 2.9/2.10.
